# Spotlight

Spotlight is a location-aware event discovery app that combines **Ticketmaster events**, **Google Places venue context**, and a **Mapbox-powered UI** so users can explore what is happening nearby and jump straight to ticket links.

<Callout title="What makes it useful">
  Spotlight groups events by venue, overlays them on an interactive map, and enriches each venue popup with ratings/open status so users can quickly decide where to go.
</Callout>

## How It Works

1. Frontend gets user coordinates (with Ann Arbor fallback).
2. Frontend requests nearby events from `GET /api/ticketmaster/search`.
3. Backend checks Upstash cache; on miss, calls Ticketmaster and caches results.
4. Frontend groups events by venue and renders one marker per venue.
5. On marker click, frontend calls `GET /api/googlePlace/search` for venue details.
6. Popup shows event list + venue metadata (rating/open status).

## API Endpoints

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/health` | Service health metadata |
| `GET` | `/api/ticketmaster/search` | Nearby events by `latitude`, `longitude`, optional `radius`, `keyword`, `startDate`, `endDate` |
| `POST` | `/api/ticketmaster/events-for-venues` | Batch events for multiple venue coordinates |
| `GET` | `/api/googlePlace/search` | Nearby places by coordinates/radius/type |
| `GET` | `/api/events/search` | Keyword/city event search (legacy route) |

## Installation & Setup

### 1) Clone and install dependencies

```bash
# from repository root
cd /home/runner/work/Spotlight/Spotlight

cd backend && npm install
cd ../frontend && npm install
```

### 2) Configure environment variables

Create `.env` in `backend/`:

```bash
PORT=3001
NODE_ENV=development
TICKETMASTER_API_KEY=your_ticketmaster_key
GOOGLE_PLACES_API_KEY=your_google_places_key
UPSTASH_REDIS_REST_URL=your_upstash_url
UPSTASH_REDIS_REST_TOKEN=your_upstash_token
MONGODB_URI=your_mongodb_uri_optional
```

Create `.env` in `frontend/`:

```bash
REACT_APP_API_BASE_URL=http://localhost:3001
REACT_APP_MAPBOX_TOKEN=your_mapbox_token
```

### 3) Run locally

```bash
# terminal 1
cd backend
npm run dev

# terminal 2
cd frontend
npm start
```

Frontend: `http://localhost:3000`  
Backend health: `http://localhost:3001/health`
